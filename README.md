# 风谷农场 · Windfield Farm

一款纯休闲治愈向的 **2.5D 写实田园割草模拟经营** 小游戏。整个游戏只有 **一个 HTML 文件**，下载后双击即可在浏览器中运行，无需安装、无需构建、无需服务器。

> 项目定位：轻量、解压、无打扰。没有任务系统、没有 NPC、没有战斗、没有广告、没有内购，只有一片会随风摆动的田、一间谷仓和不断变多的麦捆。

## 玩法简介

你在风谷里经营一片小农场。走近成熟的作物，角色会自动挥镰收割，麦捆被背在身上；背满后回到谷仓自动卸货；攒够库存就一键出售换成金币，再用金币升级装备、开垦新田，进入下一轮循环。

- 收割、卸货、出售、升级全部为自动或一键操作，重点是"走位"和"节奏"。
- 作物割完会进入再生周期：`ready → cut → empty → growing → ready`，每株在收割后 **19–30 秒** 重新长成。
- 走近成熟作物即自动收割，默认每 **0.26 秒** 收一株；背满后走到谷仓自动卸货，默认每 **0.075 秒** 存一束。
- 三种作物售价不同：小麦 6 金币 / 束、干草 4 金币 / 束、燕麦 7 金币 / 束。

## 操作方式

| 场景 | 操作 |
| --- | --- |
| 移动端 | 左下角虚拟摇杆（Pointer Events，支持触摸拖动） |
| 桌面端 | 左下角虚拟摇杆可用鼠标拖动，也可使用 `W` `A` `S` `D` 或方向键 |
| 收割 / 卸货 | 走近作物自动收割，走近谷仓自动卸货 |
| 出售 | 点击底部"出售"按钮，一次性卖出谷仓库存 |
| 升级 | 点击右侧折叠面板，按需购买 |
| 静音 | 点击音效开关，可随时关闭全部程序化音效 |

升级面板为右侧折叠面板，动画只做垂直方向进入，不做弹窗堆叠。

## 存档与音效

- **存档**：自动写入浏览器 `localStorage`，键名为 `windfield-farm-v1`；页面隐藏（切换标签页、切到后台）时立即保存。
- **音效**：全部由 WebAudio 程序化合成，包括轻柔风声，以及收割、存放、出售、升级的提示音；支持一键静音，音效状态同样写入存档。

## 技术实现要点

- **单文件架构**：HTML、CSS、JavaScript 全部内联，唯一外部依赖是 Three.js。
- **依赖**：Three.js **0.160.0**，通过 importmap 从 jsDelivr CDN 加载：

  ```html
  <script type="importmap">
  {
    "imports": {
      "three": "https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.module.js"
    }
  }
  </script>
  ```

- **零外部资源**：所有贴图（土壤、作物、木纹、石头、水面、天空等）均由 Canvas 2D 程序化绘制生成，仓库中没有任何图片、模型或字体文件。
- **2.5D 视角**：`PerspectiveCamera` 37° FOV，固定偏移 `(14, 17.2, 14)` 跟随玩家并整体抬高 4.6 单位，形成稳定的斜俯视构图。
- **渲染管线**：`ACESFilmicToneMapping`（曝光 1.06）、`PCFSoftShadowMap`（桌面 2048 / 移动 1024）、`FogExp2` 指数雾；天空与远景通过雾色和渐变融合。
- **光照**：`HemisphereLight` 环境光 + 跟随玩家的 `DirectionalLight` 太阳光（太阳缓慢漂移，光照强度与曝光做微幅呼吸）+ 一盏冷色补光。
- **实例化渲染**：农作物、草簇、野花、芦苇、围栏、石头、灌木、树冠、杂草均使用 `InstancedMesh`，以少量 draw call 渲染大量重复物体。
- **风场着色器**：通过 `material.onBeforeCompile` 注入顶点着色器，读取每个实例的 `aPhase` 属性，用时间与相位驱动麦穗和草叶摆动；不同作物使用不同的风强度。
- **作物状态机**：`ready → cut → empty → growing → ready`，收割播放倒伏动画，空置 19–30 秒后按缓动曲线重新生长。
- **角色与交互**：程序化拼装的低多边形角色，包含草帽、麦捆背负与卸货动作；作物与农田通过距离判定触发自动收割。
- **移动端适配**：渐进式 DPR 上限（移动 1.5 / 桌面 1.8）、`env(safe-area-inset-*)` 安全区适配、`touch-action: none` 防止页面滚动与缩放。

## 运行方式

### 方式一：本地双击（推荐，最简单）

1. 下载仓库中的 [`farm.html`](farm.html)。
2. 双击文件，用现代浏览器打开。
3. 首次加载需要联网，从 CDN 获取 Three.js；除此之外不请求任何外部资源。

### 方式二：在线访问（GitHub Pages 开启后）

如果仓库已开启 GitHub Pages（Source 选择 `main` 分支根目录），可直接访问：

```
https://xkx121029.github.io/windfield-farm/farm.html
```

> 说明：项目本身不需要任何构建步骤，Pages 直接托管仓库根目录即可。若链接暂时无法访问，说明 Pages 尚未开启，请按上表在仓库 Settings → Pages 中启用，或直接使用方式一。

### 浏览器要求

支持 ES Module 与 importmap 的现代浏览器：Chrome / Edge / Safari / Firefox 的近期版本。移动端建议使用系统浏览器或主流现代浏览器。
